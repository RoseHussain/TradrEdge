# TradrEdge
TradrEdge is an intelligent market-alert platform built for modern traders. It monitors NASDAQ, NSE, BSE and cryptocurrency markets in real time, measuring every price move against that asset's own behavior to separate meaningful swings from everyday noise. When something significant happens, TradrEdge delivers an instant push notification, even when the app is closed. Each alert pairs the statistical rarity of the move with a clear Buy, Sell or Hold signal, a confidence level, the reasoning behind it, and the latest headlines with images, so traders see what moved and why in a single glance. Its modular design is built to scale into personalized watchlists, custom alert rules, additional exchanges and asset classes, historical signal analysis and broker integrations, positioning TradrEdge as a complete decision-support layer for active traders.
